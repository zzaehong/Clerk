# Clerk 0.3.0

Clerk는 폴더를 선택하고 하고 싶은 일을 입력해 파일과 문서 작업을 요청하는 데스크톱 앱입니다. 선택한 폴더에서 Codex가 작업하며, 응답과 승인 요청을 앱에서 확인할 수 있습니다.

## 설치하기

Windows 10/11 64비트용입니다. 인터넷 연결과 Codex를 사용할 수 있는 ChatGPT 계정이 필요합니다. Windows 설치 파일에는 Codex가 포함되어 있습니다.

1. **Clerk_0.3.0_x64-setup.exe**를 실행합니다. 이 저장소에서 빌드한 파일은 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`에 있습니다.
2. 설치 언어를 선택하고 안내에 따라 설치합니다. WebView2가 없으면 설치 과정에서 다운로드합니다.
3. 시작 메뉴에서 **Clerk**를 실행합니다.

현재 설치 파일은 코드 서명되지 않아 Windows 보안 경고가 표시될 수 있습니다. 배포 출처를 확인한 파일만 실행하세요.

0.3.0에서는 앱·설치 프로그램·제거 프로그램이 모두 `assets/icon.png`에서 생성한 아이콘을 사용하도록 수정했습니다. 이전 0.2.0 설치 파일 대신 위의 0.3.0 설치 파일로 업데이트하세요.

## 처음 사용하기

1. **ChatGPT 로그인**을 누르고 브라우저에서 로그인을 완료합니다. 기존 Codex 로그인이 있으면 바로 연결될 수 있습니다.
2. **폴더 열기**를 눌러 작업할 폴더를 선택합니다. 처음에는 테스트용 빈 폴더로 시작하세요.
3. **하고 싶은 일** 입력란에 아래처럼 요청하고 **보내기**를 누릅니다.

   > 이 폴더에 test.md를 만들고 오늘 할 일을 3개 적어줘.

4. 승인 요청이 나오면 변경 내용이나 실행 명령을 확인하고 **이번만 허용** 또는 **거부**를 선택합니다. 추가 질문에는 답을 입력하고 **답변 보내기**를 누릅니다.
5. **작업 완료**가 표시되면 Windows 파일 탐색기에서 선택한 폴더를 열어 결과 파일을 확인합니다.

## 작업 중 사용할 기능

왼쪽 Workspace에서 폴더를 선택하고, 가운데에서 대화와 승인 요청을 확인합니다. 입력창은 하단에 유지되며 대화 영역만 스크롤됩니다. 오른쪽에는 연결 상태·사용량·작업 상태·설정이 있습니다. 좁은 창에서는 상단 Workspace / Codex 상태 버튼으로 사이드바를 열 수 있습니다. Files 영역의 파일 트리는 아직 미지원입니다.

- **사용량**: `5h limit`과 `Weekly limit`의 남은 비율·초기화 시간을 표시합니다. 로그인 시 조회하고 Codex 알림으로 갱신하며 수동 새로고침도 가능합니다. 제공되지 않는 값은 정보 없음으로 표시합니다.
- **설정**: 로그인 계정·플랜 확인, 로그인/로그아웃, Clerk·연결된 Codex 버전 확인과 재연결을 제공합니다. 내장 Codex 업데이트는 새 Clerk 설치 파일로 진행합니다.
- **채팅**: 내 요청과 Codex 답변을 구분하고, 답변의 제목·목록·표·코드 블록을 마크다운으로 표시합니다.
- **작업 중지**: 진행 중인 작업의 중지를 요청합니다. 이미 변경된 파일은 자동으로 되돌리지 않습니다.
- **폴더 변경**: 작업이 끝난 뒤 다른 폴더에서 새 대화를 시작합니다.
- **요청 원문 보기**: 승인이나 질문의 원본 정보를 확인합니다.

앱에는 파일 목록과 이전 대화 다시 열기 기능이 아직 없습니다. 결과 파일은 파일 탐색기로 확인하세요. Clerk는 Codex의 권한 설정을 따르며 별도의 승인 단계를 추가하지 않습니다. Codex가 승인을 요청한 경우에만 승인 화면을 표시합니다. 파일 변경 승인에는 생성·수정·삭제·이동할 파일 경로와 변경 내용이 표시됩니다. 명령 실행 승인에는 실행 명령·작업 폴더·요청 이유가 표시됩니다. 명령의 정확한 수정·삭제 대상 목록을 Codex가 제공하지 않으면 확인할 수 없다고 안내합니다.

## 문제가 생겼을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 로그인 브라우저가 닫혔어요 | **로그인 페이지 다시 열기**를 누르거나 **로그인 취소** 후 다시 시도하세요. |
| 폴더 열기 버튼이 비활성화되어 있어요 | Codex 연결과 로그인이 끝났는지, 작업이 진행 중인지 확인하세요. |
| Windows에서 명령이 실행되지 않아요 | **처음 실행하거나 명령 실행이 안 되나요?**를 펼쳐 **작업 환경 준비**를 누르세요. Windows 권한 확인 창이 나타날 수 있습니다. |
| 연결이 끊기거나 오류가 나요 | **오류 상세 보기**로 내용을 확인하고 **다시 연결**을 누르세요. 다시 요청하기 전에 작업 폴더에서 이미 변경된 파일이 있는지 확인하세요. |

## 파일과 계정

파일은 선택한 PC의 폴더에서 작업합니다. AI 처리에는 인터넷 연결이 필요하며, 요청과 작업에 필요한 내용은 Codex가 계정의 모델 서비스로 전송할 수 있습니다. 로그인 정보와 Codex 기록은 PC의 Codex가 관리합니다.

현재 버전은 시험 사용 단계입니다. 설치 후 로그인 → 폴더 선택 → 승인 → 파일 생성까지의 Windows GUI 전체 흐름은 아직 검증되지 않았습니다.

개발 환경, 빌드 및 테스트 방법은 [개발 안내](doc/development.md), 확인된 동작과 남은 검증은 [검증 기록](doc/verification.md)을 참고하세요.
